# Employee Training Feedback System

A responsive web based Employee Training Feedback System developed using HTML, CSS and JavaScript.

## About the Project

The Employee Training Feedback System allows employees to submit feedback about training programs and provides a simple dashboard for viewing and managing feedback.

## Features

• Employee feedback submission

• Star based rating system

• Automatic average rating calculation

• Feedback dashboard

• Feedback records

• Edit feedback

• Delete feedback

• Responsive corporate user interface

• Interactive user experience

## Technologies Used

HTML5

CSS3

JavaScript

Local Storage
